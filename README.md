# Hackathon Idea: Lounge-Optimized Traveling Agent

**Theme**: Traveling Agents with access to Google Cloud, Gemini Vertex, and Lufthansa API.

**Idea**: An autonomous agent that maximizes the time a traveler spends in Lufthansa lounges during their journey. It's an inverse "Traveling Salesman" problem where layovers are optimized for comfort rather than minimized.
